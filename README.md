# Common Cyber Attacks and How They Work | Cybersecurity in Kerala

Cyber attacks are becoming increasingly common as people and businesses depend
more on digital technology.

This guide explains common cyber attacks and basic ways to stay protected.

## Common Cyber Attacks

### 1. Phishing
Phishing uses fake emails, messages, or websites to trick users into revealing
sensitive information.

### 2. Malware
Malware is malicious software that can damage systems, steal information, or
disrupt normal operations.

### 3. Ransomware
Ransomware can prevent users from accessing their files or systems and may
demand payment from victims.

### 4. Password Attacks
Weak or reused passwords can increase the risk of unauthorized account access.

### 5. DoS and DDoS
These attacks attempt to make online services unavailable by overwhelming them
with traffic or requests.

### 6. Man-in-the-Middle Attacks
An attacker attempts to intercept communication between two parties.

### 7. SQL Injection
SQL injection is a web application vulnerability that can occur when user
input is not properly handled before database queries are processed.

### 8. Social Engineering
Social engineering manipulates people into revealing information or performing
actions that may create security risks.
